# الشغيل (ALSHAGHEEL) — Multiplayer prototype v1.1

لعبة محاكاة حياة/متجر عربية تعمل كواجهة ثابتة على Netlify وخادم Socket.IO على Render.

## تشغيل محلي
- Node.js 20+
- `npm install`
- `npm start`
- افتح `http://localhost:3000`

## النشر الصحيح (لا تتخطّ خطوة الخادم)
1. ارفع **محتويات هذا المشروع بالكامل** إلى مستودع GitHub، بحيث يكون `package.json` و`server.js` في جذر المستودع، والمجلد `public/` بجانبهما.
2. في Render أنشئ **New → Web Service** من المستودع؛ Build Command: `npm install`، Start Command: `npm start`، Health Check Path: `/health`، وNode 20. انتظر حالة Live. افتح `https://YOUR-SERVICE.onrender.com/health` ويجب أن ترى JSON فيه `"ok":true` و`"game":"الشغيل"`.
3. ارفع **ملفات داخل `public/` فقط** إلى Netlify، أو اربط Netlify بالمستودع مع Publish directory = `public`.
4. داخل شاشة البداية على Netlify افتح «إعداد اتصال اللعب الجماعي»، والصق **رابط Render** وليس رابط Netlify، ثم اضغط «اختبر الاتصال واحفظ الرابط». لا تستخدم `https://ma3ashat.netlify.app` أو رابط Netlify في خانة خادم الغرف.
5. بعد نجاح اختبار الخادم، أنشئ غرفة وخذ الرمز من داخل اللعبة وشاركه مع أصدقائك؛ يدخلون نفس موقع Netlify، ويلصقون رابط Render مرة واحدة على أجهزتهم ثم يكتبون رمز الغرفة.

## استكشاف الأعطال
- إذا `/health` لا يعرض JSON `ok:true`, فخدمة الخادم لم تنشر بنجاح أو تستخدم عنواناً خاطئاً.
- إذا الرابط يعمل في المتصفح لكن الاختبار يفشل، راجع Logs في Render وتأكد أن خدمة الويب ما زالت Live.
- خدمة الاستضافة المجانية قد تنام؛ أول اتصال قد يحتاج بعض الوقت. أعد اختبار الاتصال إذا انتهت المهلة.
- للادخار المستمر على Render، استخدم Persistent Disk أو قاعدة بيانات؛ `saves.json` على نظام ملفات مؤقت قد يُفقد عند إعادة النشر/إعادة التشغيل.

تنبيه: هذه نسخة أولية وليست لعبة تجارية نهائية، ويجب اختبار الصوت/المزامنة بأجهزة متعددة بعد النشر الفعلي.
